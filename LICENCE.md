## 🧩 About

**Vermintide 2 Mod Menu** is a curated list of Vermintide 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, widget toggles, menu panel
- **Quality-of-Life Helpers** — loadout notes, loot tracker, HUD tweaks
- **Research Notes** — build layouts and config notes for educational use

## ✨ Features

### ESP
- Widget Toggles — show or hide HUD elements for study
- Range Notes — visualize melee and ranged reach
- Replay Notes — record and review run footage
- Playback Speed — adjust demo playback for study (0.25x to 4x)

### Wallhack
- Loadout Catalog — browse weapons, trinkets, and traits
- Skin Notes — organize hero cosmetics
- HUD Layout — rearrange interface elements

### Aimbot
- Practice Mode Notes — segment study on any map
- Difficulty Toggles — manually adjust settings for drills
- Input Buffer Notes — chain complex maneuvers in practice
